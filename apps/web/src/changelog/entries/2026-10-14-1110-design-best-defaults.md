# Better new ship designs
- New ship designs start with your best shield and best combat computer already fitted, alongside your best armor, like the original design template.
- New designs get a fitting name in your race's style, such as Kestrel for an avian frigate or Hive Mother for an insectoid battleship. Escorts and capital ships draw from different name lists, and names you already use are skipped.
- Designs can now be edited: press Edit on a design, change it and Save changes. Colonies build the new version from then on, including ships already queued.
- Ships built before the edit keep their old equipment and show an "outdated" mark when you select their fleet, with what a refit to the new version costs. Refit picks the new version for them by default.
