# Idle colonies earn Trade Goods
- A colony with nothing queued no longer says its industry is wasted: it shows the BC its industry earns as Trade Goods.
- Ending the turn now lists colonies making only Trade Goods, in the same check that warns about unchosen research, with each colony's BC and a button to open it.
- This alert is on by default and can be turned off for the current game only, from that check or the Game menu.
