# StarLord on cued

- StarLord can run as a guest game on cued: opened from there, it shows your cued name and avatar on the title screen, and online games use your cued name.
- Yes/no questions (quit, declare war, scrap ships and the like) now open in the game instead of the browser's own box, so they also work inside other pages.
- Copying the invite link works inside other pages too. Inside cued, downloading save files is off (cued's frame blocks downloads), and the button says why.
