# Debug menu
- Hold Ctrl+Alt while clicking "Play as…" on the new game screen to start a game with the debug menu. Open it with the Debug button in the top bar or F9.
- It can unlock the full tech tree (optionally with Vexari tech), finish the current research, add research points or BC, finish every build this turn and set a colony's population.
- It can also explore every system, meet every empire, spawn ships of any of your designs, send a Vexari raid at you and trigger any random event.
- Debug orders are ordinary orders for the turn, so Undo takes them back, and saved games keep their debug menu.
