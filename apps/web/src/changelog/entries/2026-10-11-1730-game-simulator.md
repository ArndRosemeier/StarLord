# Game simulator in the debug menu

- The debug menu (start a game holding Ctrl+Alt, or hold the start button on a tablet) has a game simulator: it plays whole computer-only games in the background across the galaxy sizes and empire counts you pick, and shows how each ended, how long it took and any crash or broken rule.
- Tap a simulated game to see every empire's colonies, population, techs, ships and score, what happened during the game, and which AI orders the rules turned down.
- Your own game is untouched, and the simulator keeps going while the menu is closed.
