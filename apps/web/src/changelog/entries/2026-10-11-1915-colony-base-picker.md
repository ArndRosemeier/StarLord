# Colony bases ask where to go

- A finished Colony Base, Outpost Base or Artificial Planet now asks which planet in the system it goes to, like the original. Each choice shows the new colony's room for population (or what the planet becomes), with the best one marked.
- With only one free planet it settles there on its own.
- A base can no longer vanish: you can't queue more bases than there are free planets, and if every planet is taken before it is used, it is scrapped for half its cost and the turn report says so.
