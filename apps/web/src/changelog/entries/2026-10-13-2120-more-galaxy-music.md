# More music for the galaxy map

- Five new background tracks for the galaxy map: warm strings, deep-space ambient, a retro synth groove, an ancient-ruins flute theme and a quiet piano piece.
- The galaxy music now shuffles through all seven tracks, plays every one before any repeats and never plays the same track twice in a row.
- After a battle the map music picks up with a different track instead of starting the same one again.
